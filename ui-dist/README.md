# UI z Lovable (adminphmedia/orca-radio-airwave)
Obsah této složky je build `bun run build:orca` (složka `dist/client`) z Lovable projektu.
Desktopová aplikace i `orca-server` ho zobrazují místo vestavěného panelu.

Aktualizace ručně: v UI repozitáři `bun install && bun run build:orca`, pak obsah `dist/client/` nakopírovat sem.
Aktualizace automaticky: viz komentář v `.github/workflows/release.yml` (LOVABLE_UI_REPO + UI_REPO_TOKEN).
